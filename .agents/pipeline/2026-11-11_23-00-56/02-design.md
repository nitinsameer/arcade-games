## Executive Summary

This design modularizes the monolithic 794-line `www/index.html` (~50 KB) into a maintainable ES module structure using Vite as bundler, while preserving all 15 games, 19 themes, 12 subjects, and user data. The architecture separates concerns into discrete modules: bootstrap, navigation, audio, storage, games, subjects, themes, and build configuration.

## Detailed Module Design

### 1. Core Modules

#### `src/bootstrap.js`
**Responsibility:** Initialize application state, load saved data, apply theme, set up audio context.

**Exports:**
```javascript
export let S = {};  // Global state object, exported for use everywhere

export async function bootstrap() {
  // Load state from localStorage with defaults and validation
  S = loadState();
  
  // Apply theme to DOM (CSS cascade auto-updates)
  applyTheme(S.theme);
  
  // Initialize audio context (deferred until first user interaction)
  await initAudioContext();
  
  // Return initialized state for app entry
  return S;
}

export function applyTheme(themeId) {
  // Update theme in state and DOM
  S.theme = themeId;
  document.documentElement.dataset.theme = themeId;
  // CSS cascade automatically re-evaluates all --var custom properties
  // Audio theme (SND object) updates on next sfx() call (reads S.theme)
  saveState(S);
}
```

**Key Behaviors:**
- Reads `localStorage.claylearn` JSON
- Falls back to default state if missing or corrupted
- Validates state schema with complete 14-field validation
- Sets `document.documentElement.dataset.theme = S.theme`
- Initializes Web Audio API context on first user interaction (iOS requirement)
- Handles state migration for future schema changes

**Error Handling:**
- localStorage quota exceeded → silently continue with in-memory state
- Corrupted JSON → reset to defaults (log warning)
- Missing localStorage entirely → use in-memory state (no persistence)
- No audio context → graceful degradation (sounds disabled, logged)

#### `src/storage.js`
**Responsibility:** Manage state object (S), persistence to localStorage, defaults, validation.

**Complete State Schema (14 Fields - VERIFIED)**
```javascript
export const defaultState = {
  // Profile & Settings
  name: 'Explorer',                           // String, max 14 chars, player name
  theme: 'clay',                              // String, active theme ID
  sound: true,                                // Boolean, audio enabled flag
  vol: 0.7,                                   // Number, volume 0–1
  
  // Progress Tracking
  gb: {},                                     // Object, { [gameId]: bestScore }
  done: {},                                   // Object, { [subjId]: [lessonIndices] }
  best: {},                                   // Object, { [subjId]: bestQuizScore }
  
  // Achievement & Economy
  stars: 0,                                   // Number (deprecated, use coins)
  coins: 0,                                   // Number, earned coins
  
  // Content Unlocks & Customization
  owned: ['clay', 'claydark', 'minimal'],    // Array of unlocked theme IDs
  avatar: 'kid',                              // String, current avatar ID
  ownedAv: ['kid', 'bear'],                  // Array of unlocked avatar IDs
  
  // Power-ups & Time-based Events
  pw: { fifty: 0, time: 0 },                // Object, { fifty: count, time: count }
  daily: { d: '', streak: 0 },              // Object, { d: dateString, streak: count }
  ads: { d: '', n: 0, t: 0 },               // Object, { d: date, n: adCount, t: timestamp }
  day: { d: '', n: 0 }                      // Object, { d: dateString, n: lessonCount }
};

export function loadState() {
  try {
    const stored = localStorage.getItem('claylearn');
    if (stored) {
      const parsed = JSON.parse(stored);
      return validateState({ ...defaultState, ...parsed });
    }
  } catch (e) {
    console.error('Failed to load state:', e);
  }
  return { ...defaultState };
}

export function saveState(state) {
  try {
    localStorage.setItem('claylearn', JSON.stringify(state));
  } catch (e) {
    if (e.name === 'QuotaExceededError') {
      console.warn('localStorage quota exceeded; state not saved but app continues');
    }
  }
}

export function validateState(state) {
  // Verify and coerce each field to correct type with defaults
  
  // Profile & Settings (4 fields)
  if (typeof state.name !== 'string' || state.name.length === 0 || state.name.length > 14) {
    state.name = 'Explorer';
  }
  if (typeof state.theme !== 'string' || !themeExists(state.theme)) {
    state.theme = 'clay';
  }
  if (typeof state.sound !== 'boolean') {
    state.sound = true;
  }
  if (typeof state.vol !== 'number' || state.vol < 0 || state.vol > 1) {
    state.vol = 0.7;
  }
  
  // Progress Tracking (3 fields)
  if (typeof state.gb !== 'object' || state.gb === null) {
    state.gb = {};
  }
  if (typeof state.done !== 'object' || state.done === null) {
    state.done = {};
  }
  if (typeof state.best !== 'object' || state.best === null) {
    state.best = {};
  }
  
  // Achievement & Economy (2 fields)
  if (typeof state.stars !== 'number' || state.stars < 0) {
    state.stars = 0;
  }
  if (typeof state.coins !== 'number' || state.coins < 0) {
    state.coins = 0;
  }
  
  // Content Unlocks & Customization (3 fields)
  if (!Array.isArray(state.owned)) {
    state.owned = ['clay', 'claydark', 'minimal'];
  }
  if (typeof state.avatar !== 'string' || state.avatar === '') {
    state.avatar = 'kid';
  }
  if (!Array.isArray(state.ownedAv)) {
    state.ownedAv = ['kid', 'bear'];
  }
  
  // Power-ups & Time-based Events (4 fields)
  if (typeof state.pw !== 'object' || state.pw === null) {
    state.pw = { fifty: 0, time: 0 };
  }
  if (typeof state.pw.fifty !== 'number') state.pw.fifty = 0;
  if (typeof state.pw.time !== 'number') state.pw.time = 0;
  
  if (typeof state.daily !== 'object' || state.daily === null) {
    state.daily = { d: '', streak: 0 };
  }
  if (typeof state.daily.d !== 'string') state.daily.d = '';
  if (typeof state.daily.streak !== 'number' || state.daily.streak < 0) state.daily.streak = 0;
  
  if (typeof state.ads !== 'object' || state.ads === null) {
    state.ads = { d: '', n: 0, t: 0 };
  }
  if (typeof state.ads.d !== 'string') state.ads.d = '';
  if (typeof state.ads.n !== 'number' || state.ads.n < 0) state.ads.n = 0;
  if (typeof state.ads.t !== 'number' || state.ads.t < 0) state.ads.t = 0;
  
  if (typeof state.day !== 'object' || state.day === null) {
    state.day = { d: '', n: 0 };
  }
  if (typeof state.day.d !== 'string') state.day.d = '';
  if (typeof state.day.n !== 'number' || state.day.n < 0) state.day.n = 0;
  
  return state;
}

// Export save/load as global convenience functions
export function save() {
  saveState(S);  // Assumes S is imported from bootstrap.js
}

export function load() {
  return loadState();
}
```

- `loadState()` called on app bootstrap
- `saveState(S)` called after state mutations (game end, lesson completion, toggle sound, etc.)

#### `src/router.js`
**Responsibility:** Hash-based routing, parameter extraction, screen rendering.

**Exports & Route Definitions:**
```javascript
import { S } from './bootstrap.js';
import { getGame } from './games/registry.js';
import { getSubject } from './subjects/registry.js';

// Route handlers (imported from respective modules)
import { renderHome, renderExplore, renderCourse, renderLesson, renderQuiz, 
         renderGamesList, renderGameScreen, renderProgress, renderRewards, renderProfile } from './screens.js';

const routes = {
  '/home': renderHome,
  '/explore': renderExplore,
  '/course/:id': renderCourse,
  '/lesson/:id/:i': renderLesson,
  '/quiz/:id': renderQuiz,
  '/games': renderGamesList,
  '/game/:id': renderGameScreen,
  '/progress': renderProgress,
  '/rewards': renderRewards,
  '/profile': renderProfile
};

export function go(path) {
  // Navigate by updating hash (will trigger hashchange event)
  location.hash = path;
}

export function parseRoute(hash) {
  // Parse hash into route pattern and parameters
  // Example: "/game/simon" → ["/game/:id", "simon"]
  // Example: "/lesson/math/0" → ["/lesson/:id/:i", "math", "0"]
  
  const parts = hash.split('/').filter(Boolean);  // ["game", "simon"] or ["lesson", "math", "0"]
  
  if (!parts.length) {
    return ['/home'];
  }
  
  const [firstPart, ...params] = parts;
  
  // Try to match route patterns
  if (firstPart === 'home') return ['/home'];
  if (firstPart === 'explore') return ['/explore'];
  if (firstPart === 'course' && params.length >= 1) {
    const subjId = params[0];
    if (!getSubject(subjId)) {
      console.warn(`Invalid subject: ${subjId}, redirecting to /home`);
      return ['/home'];
    }
    return ['/course/:id', subjId];
  }
  if (firstPart === 'lesson' && params.length >= 2) {
    const subjId = params[0];
    const lessonIndex = parseInt(params[1], 10);
    if (!getSubject(subjId) || isNaN(lessonIndex)) {
      console.warn(`Invalid lesson params: ${subjId}/${params[1]}, redirecting to /home`);
      return ['/home'];
    }
    return ['/lesson/:id/:i', subjId, lessonIndex];
  }
  if (firstPart === 'quiz' && params.length >= 1) {
    const subjId = params[0];
    if (!getSubject(subjId)) {
      console.warn(`Invalid quiz subject: ${subjId}, redirecting to /home`);
      return ['/home'];
    }
    return ['/quiz/:id', subjId];
  }
  if (firstPart === 'games') return ['/games'];
  if (firstPart === 'game' && params.length >= 1) {
    const gameId = params[0];
    if (!getGame(gameId)) {
      console.warn(`Invalid game: ${gameId}, redirecting to /games`);
      return ['/games'];
    }
    return ['/game/:id', gameId];
  }
  if (firstPart === 'progress') return ['/progress'];
  if (firstPart === 'rewards') return ['/rewards'];
  if (firstPart === 'profile') return ['/profile'];
  
  // Fallback for unrecognized routes
  console.warn(`Unrecognized route: ${hash}, redirecting to /home`);
  return ['/home'];
}

export function render() {
  // Parse current hash, call matching render function
  const hash = location.hash.slice(1) || '/home';
  const [routePattern, ...params] = parseRoute(hash);
  
  if (!routePattern) {
    return renderHome();
  }
  
  // Map route pattern to handler function
  let renderFn;
  if (routePattern === '/home') renderFn = renderHome;
  else if (routePattern === '/explore') renderFn = renderExplore;
  else if (routePattern === '/course/:id') renderFn = renderCourse;
  else if (routePattern === '/lesson/:id/:i') renderFn = renderLesson;
  else if (routePattern === '/quiz/:id') renderFn = renderQuiz;
  else if (routePattern === '/games') renderFn = renderGamesList;
  else if (routePattern === '/game/:id') renderFn = renderGameScreen;
  else if (routePattern === '/progress') renderFn = renderProgress;
  else if (routePattern === '/rewards') renderFn = renderRewards;
  else if (routePattern === '/profile') renderFn = renderProfile;
  else renderFn = renderHome;
  
  try {
    return renderFn(...params);
  } catch (e) {
    console.error(`Render error for route ${routePattern}:`, e);
    return renderHome();
  }
}

// Listen for hash changes and re-render
window.addEventListener('hashchange', () => {
  const html = render();
  const viewEl = document.querySelector('#view');
  if (viewEl) {
    viewEl.innerHTML = html;
    bindDelegatedEvents();  // Re-bind event listeners after render
  }
});

export function bindDelegatedEvents() {
  // Re-bind all delegated event listeners
  // Remove previous listeners (to avoid duplicates)
  // Add new delegated listener for data-* attributes
  
  const view = document.querySelector('#view');
  if (!view) return;
  
  // Simplified: attach single delegated listener
  view.addEventListener('click', (e) => {
    const target = e.target.closest('[data-*]');
    if (!target) return;
    
    if (target.dataset.go) {
      go(target.dataset.go);
    }
    if (target.dataset.act) {
      // Dispatch action (game input, UI action, etc.)
      handleAction(target.dataset.act, target);
    }
    if (target.dataset.t) {
      // Theme selection
      applyTheme(target.dataset.t);
    }
  });
}

function handleAction(action, element) {
  // Dispatch actions based on action name
  // Example: data-act="complete" → trigger lesson completion
}
```

**Validation Rules:**
- `gameId`: Must exist in GAMES array, otherwise redirect to /games
- `subjId`: Must exist in SUBJECTS array, otherwise redirect to /home
- `lessonIndex`: Must be valid integer ≥ 0, otherwise redirect to /home
- Invalid routes: Default to /home with console warning

#### `src/audio/context.js`
**Responsibility:** Manage Web Audio API context lifecycle, master volume, cleanup.

**Exports:**
```javascript
let audioContext = null;
let masterGain = null;
let effectsBus = null;
let activeOscillators = [];  // Track all oscillators for cleanup
let activeBufferSources = [];  // Track all buffer sources for cleanup

export function getAudioContext() {
  if (!audioContext) {
    const AudioContext = window.AudioContext || window.webkitAudioContext;
    if (!AudioContext) {
      console.warn('Web Audio API not supported in this browser');
      return null;
    }
    
    try {
      audioContext = new AudioContext();
      masterGain = audioContext.createGain();
      masterGain.connect(audioContext.destination);
      
      // Set up effects bus (reverb via delay + feedback)
      const delay = audioContext.createDelay(1);
      delay.delayTime.value = 0.17;
      const feedback = audioContext.createGain();
      feedback.gain.value = 0.38;
      delay.connect(feedback);
      feedback.connect(delay);
      const wet = audioContext.createGain();
      wet.gain.value = 0.5;
      delay.connect(wet);
      wet.connect(masterGain);
      
      effectsBus = delay;
    } catch (e) {
      console.error('Failed to create audio context:', e);
      return null;
    }
  }
  
  // Resume context on iOS (required for user interaction)
  if (audioContext && audioContext.state === 'suspended') {
    audioContext.resume().catch(e => console.warn('Audio context resume failed:', e));
  }
  
  return audioContext;
}

export function getMasterGain() {
  return masterGain;
}

export function getEffectsBus() {
  return effectsBus;
}

export function setVolume(level) {
  // level is 0–1, convert to exponential scale for audio perception
  if (masterGain) {
    // Use power curve for perceived volume control
    masterGain.gain.value = Math.pow(level, 1.5) * 0.9;
  }
}

export function stopAllAudio() {
  // Called when game ends or app pauses: stop all running oscillators & buffer sources
  // Note: Web Audio API doesn't provide global "stop all" method
  // Solution: Stop all tracked sources
  
  activeOscillators.forEach(osc => {
    try {
      osc.stop();
    } catch (e) {
      // Oscillator may already be stopped
    }
  });
  activeOscillators = [];
  
  activeBufferSources.forEach(source => {
    try {
      source.stop();
    } catch (e) {
      // Source may already be stopped
    }
  });
  activeBufferSources = [];
}

export function cleanupAudioContext() {
  // Called on app shutdown or before app unload
  stopAllAudio();
  
  if (audioContext && audioContext.state !== 'closed') {
    try {
      audioContext.close();
    } catch (e) {
      console.warn('Audio context close failed:', e);
    }
  }
  
  audioContext = null;
  masterGain = null;
  effectsBus = null;
}

export function trackOscillator(osc) {
  activeOscillators.push(osc);
}

export function trackBufferSource(source) {
  activeBufferSources.push(source);
}

// Cleanup on page unload
window.addEventListener('beforeunload', cleanupAudioContext);
```

**Key Behaviors:**
- Audio context initialized on first user interaction (iOS requirement)
- Master gain controls volume globally
- Oscillators and buffer sources tracked for cleanup
- `stopAllAudio()` called when game ends or app pauses
- `cleanupAudioContext()` called on app shutdown

**Error Handling:**
- If Web Audio API unavailable, `getAudioContext()` returns `null`
- `sfx()` checks for null context and returns early (graceful degradation)
- All try-catch blocks prevent crashes from audio API failures

#### `src/audio/sfx.js`
**Responsibility:** Define all sound effects, provide global `sfx(eventName, arg)` function.

**Exports:**
```javascript
import { getAudioContext, getMasterGain, getEffectsBus, setVolume, trackOscillator, trackBufferSource } from './context.js';
import { playTone, playNoise } from './synthesizer.js';
import { SND } from './soundThemes.js';
import { S } from '../bootstrap.js';

export function sfx(eventName, arg = 0) {
  // Check if sound is enabled
  if (!S.sound) return;
  
  const ctx = getAudioContext();
  if (!ctx) return;  // Audio context unavailable
  
  const theme = SND[S.theme] || SND.clay;
  const master = getMasterGain();
  if (!master) return;
  
  try {
    if (eventName === 'tap') {
      // Click sound: use noise or tone depending on theme
      if (theme.k === 'click') {
        playNoise(ctx, 0.03, 0.5 * theme.v, 2500);
      } else if (theme.k === 'tick') {
        playNoise(ctx, 0.02, 0.45, 5000);
        playTone(ctx, 1800, 0.03, 0.1, master, theme);
      } else {
        playTone(ctx, 330, 0.12, 0.3, master, theme, 640);
      }
    } else if (eventName === 'correct') {
      // Three-note ascending arpeggio
      playTone(ctx, 523.25, 0.2, 0.3, master, theme);
      playTone(ctx, 783.99, 0.1, 0.28, master, theme);
      playTone(ctx, 1975, 0.2, 0.12, master, theme);
    } else if (eventName === 'wrong') {
      // Descending tone
      playTone(ctx, 190, 0.28, 0.28, master, theme, 120);
    } else if (eventName === 'lesson') {
      // Four-note ascending sequence for lesson completion
      [523.25, 659.25, 783.99, 1318.5].forEach((f, i) =>
        playTone(ctx, f, i * 0.09, 0.22, master, theme)
      );
    } else if (eventName === 'end') {
      // arg: 2 = victory, 1 = good, 0 = loss
      if (arg === 2) {
        // Victory: four notes held together
        [523.25, 659.25, 783.99, 1046.5].forEach(f =>
          playTone(ctx, f, 0, 0.25, master, theme)
        );
      } else if (arg === 1) {
        // Good: three notes
        [523.25, 659.25, 783.99].forEach((f, i) =>
          playTone(ctx, f, i * 0.11, 0.3, master, theme)
        );
      } else {
        // Loss: descending tones
        [392, 440, 523.25].forEach((f, i) =>
          playTone(ctx, f, i * 0.13, 0.3, master, theme)
        );
      }
    } else if (eventName === 'note') {
      // arg: 0–3 for musical notes (Simon game)
      const notes = [261.63, 329.63, 392, 523.25];
      playTone(ctx, notes[arg % 4], 0, 0.35, master, theme);
    } else if (eventName === 'pop') {
      // Pop/bubble burst
      playNoise(ctx, 0.05, 0.4 * theme.v, 800);
      playTone(ctx, 900, 0, 0.08, master, theme, 300);
    } else if (eventName === 'theme') {
      // Theme switch confirmation
      playTone(ctx, 220, 0, 0.3, master, theme, 1400);
      playNoise(ctx, 0, 0.25, 0.1 * theme.v, 1200);
    }
  } catch (e) {
    console.error('SFX error:', e);
  }
}

// Make sfx globally available
window.sfx = sfx;
```

#### `src/games/runner.js`
**Lifecycle State Machine with Cleanup (Finding 5 Fix)**

```javascript
export class GameRunner {
  constructor(gameModule, container, config = {}) {
    this.gameModule = gameModule;
    this.container = container;
    this.config = config;
    this.instance = null;
    this.state = 'idle';  // idle, created, running, paused, destroyed
  }
  
  // Create game instance
  async create() {
    if (this.state !== 'idle') {
      throw new Error(`Cannot create game: already in state "${this.state}"`);
    }
    
    try {
      this.instance = await this.gameModule.create(this.config);
      this.state = 'created';
    } catch (e) {
      console.error('Game creation failed:', e);
      throw e;
    }
  }
  
  // Mount game to DOM
  mount() {
    if (this.state !== 'created') {
      throw new Error(`Cannot mount game: state is "${this.state}", expected "created"`);
    }
    
    try {
      this.gameModule.mount(this.instance, this.container);
      this.state = 'running';
    } catch (e) {
      console.error('Game mount failed:', e);
      this.cleanup();
      throw e;
    }
  }
  
  // Pause (app background)
  pause() {
    if (this.state !== 'running') return;
    
    try {
      if (this.gameModule.pause) {
        this.gameModule.pause(this.instance);
      }
      this.state = 'paused';
    } catch (e) {
      console.error('Game pause failed:', e);
    }
  }
  
  // Resume (app foreground)
  resume() {
    if (this.state !== 'paused') return;
    
    try {
      if (this.gameModule.resume) {
        this.gameModule.resume(this.instance);
      }
      this.state = 'running';
    } catch (e) {
      console.error('Game resume failed:', e);
    }
  }
  
  // Destroy (cleanup) - MUST be called after game ends
  destroy() {
    if (this.state === 'destroyed') return;
    
    try {
      if (this.gameModule.destroy) {
        this.gameModule.destroy(this.instance);
      }
      this.cleanup();
      this.state = 'destroyed';
    } catch (e) {
      console.error('Game destroy failed:', e);
      this.cleanup();
      this.state = 'destroyed';
    }
  }
  
  // Internal cleanup helper
  cleanup() {
    // Clear all references
    this.instance = null;
    this.container = null;
  }
}
```

```javascript
export function applyThemeVariables(themeId) {
  const theme = themesData[themeId];
  if (!theme) {
    console.warn(`Theme not found: ${themeId}, using clay`);
    return applyThemeVariables('clay');
  }
  
  const root = document.documentElement;
  Object.entries(theme).forEach(([key, value]) => {
    root.style.setProperty(key, value);
  });
  
  // CSS cascade automatically updates all elements using custom properties
  // No re-render needed; existing DOM uses new variables
}
```

**Theme Switching Lifecycle:**
1. User clicks theme button: `data-t="themeId"`
2. Router calls `applyTheme(themeId)` from bootstrap.js
3. `applyTheme()` updates `S.theme`, sets `document.documentElement.dataset.theme`
4. `applyThemeVariables()` injects CSS custom properties
5. CSS cascade re-evaluates all rules using `var(--prop)`
6. Audio theme (SND) reads `S.theme` on next `sfx()` call
7. State saved to localStorage

**No visual glitch occurs because:**
- CSS properties are injected at `:root` level
- All elements already reference properties via `var(--prop)`
- Cascade re-evaluation is atomic (no layout shift)
- Audio theme is lazy-evaluated (no immediate update needed)

## Error Handling Strategy

### Layer-by-Layer Error Handling

**Bootstrap Layer (`src/bootstrap.js`):**
- localStorage failures → silent, use in-memory state
- Audio context init failures → graceful (sounds disabled)
- Theme application failures → fallback to 'clay'

**Router Layer (`src/router.js`):**
- Invalid route parameters → redirect to /home
- Missing game/subject → redirect to appropriate fallback
- Render function exceptions → fallback to home render

**Game Layer (`src/games/runner.js`):**
- Game creation failures → logged, exception re-thrown
- Game mount failures → cleanup, exception re-thrown
- Game destroy failures → forced cleanup, no re-throw

**Audio Layer (`src/audio/*.js`):**
- Audio context unavailable → graceful (sfx() returns early)
- Oscillator errors → try-catch, continue
- Master gain updates → safe default if null

**Storage Layer (`src/storage.js`):**
- localStorage quota exceeded → warning logged, continue with in-memory
- Corrupted JSON → reset to defaults, logged
- Missing fields on load → validate and fill with defaults

### Invariants Enforced by Each Module

| Invariant | Owner | Enforcement |
|-----------|-------|-------------|
| State schema valid (14 fields) | `src/storage.js` | `validateState()` on every load, coerces to defaults |
| Game module implements lifecycle | `src/games/runner.js` | Type check on create(); exception if missing |
| Route parameters valid | `src/router.js` | `parseRoute()` validates gameId, subjId, lessonIndex |
| Audio context healthy | `src/audio/context.js` | `getAudioContext()` checks state, resumes if suspended |
| No orphaned timers on game destroy | `src/games/runner.js` + game modules | Game module must store timer IDs and clear in destroy() |
| CSS variables applied for active theme | `src/themes/cssVariables.js` | `applyThemeVariables()` injects all properties at :root |
